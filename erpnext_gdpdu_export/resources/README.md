# resources/

Hier gehört die Original-DTD `gdpdu-01-08-2002.dtd` der Audicon GmbH hin
(unverändert). Sie ist **nicht** Teil dieses Repositories — Redistribution-Frage
siehe KONZEPT.md §7.1; `.gitignore` verhindert das versehentliche Einchecken.

Zwei Wege, die Datei bereitzustellen:

1. **Empfohlen für Anwender:** im Desk unter *GDPdU Export Settings* hochladen.
   Die Einstellung hat Vorrang vor dieser Datei.
2. **Für Administratoren:** die Datei hier ablegen; alle Sites dieser Instanz
   verwenden sie dann automatisch.

Ohne DTD läuft der Export weiter, das Paket ist aber unvollständig und die
`index.xml` wird nicht validiert — beides steht deutlich im Prüfprotokoll.

Quelle des Beschreibungsstandards inkl. DTD:
https://www.caseware.net/fileadmin/audicon/media/allgemeine_bilder/Beschreibungsstandard-GDPdU-01-03-2019.pdf
